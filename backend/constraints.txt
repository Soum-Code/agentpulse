# Exact versions of every package in the backend image that ran correctly on Azure
# (python:3.11-slim, linux x86_64), taken with `pip freeze` from that image.
#
# Why this file exists: pyproject.toml only gives ranges, so a rebuild picks up whatever
# is newest that day. The rebuild on 2026-10-19 pulled SQLAlchemy 2.1.5, fastapi 0.146,
# pydantic 2.14, starlette 1.9 and sqlmodel 0.0.48 together, and the new image crashed on
# start with "ImportError: greenlet". These pins make a rebuild give the same packages
# the running image has.
#
# torch is not listed: the Dockerfiles install it first from PyTorch's CPU index
# (pinned there), and the CPU build has a "+cpu" tag that PyPI installs do not.
#
# Used with:   pip install -c constraints.txt .
# A constraints file only limits versions; it never adds packages by itself.
#
# To move to newer versions on purpose: build the image from pyproject.toml alone, run the
# backend tests inside it, then regenerate this file with
#   docker run --rm --entrypoint /venv/bin/pip <image> freeze
# (drop the agentpulse-backend and torch lines) and commit it with the change that needed it.
