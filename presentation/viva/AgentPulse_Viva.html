Grounding failure

An agent states something its own evidence does not support, and the next agent builds on it.

Behavioural drift

An agent's answers move away from how it used to answer, after a model or prompt change. Nothing errors.

Quality is an add-on

Existing tools trace tokens, latency and cost well, but treat quality evaluation as optional and sampled.

Goal of this project: score every span, cheaply enough for a CPU, and show plainly what was not measured. Framing from README.md (intro paragraph).

03 · Signal 1 · Grounding

Grounding risk: an NLI model, not a judge

risk = P(contradiction) + 0.3 × P(neutral)

DeBERTa-v3-small compares an agent's output with the evidence it was given. 0 = safe, 1 = risky. High above 0.7, medium above 0.4.

contradictedunverifiablesupported

The verdict is whichever probability is highest. Unverifiable = the evidence neither supports nor contradicts. A status, not a pass.

0.3 is a design choice, not a fit: weights 0.0 to 0.3 cannot be told apart on this data.

2:20-3:30. The score is the NLI model's probabilities, not an LLM's opinion. Contradiction counts fully; neutral counts 0.3. Cut-offs 0.7 (high) and 0.4 (medium), strict ">". Say plainly: 0.3 is a design choice. On the corrected labels, weights 0.0 to 0.3 give identical results; the one case that separates them is val_17. At 0.5 the medium band flagged 7 of 17 supported test cases (FPR 0.412), which is why 0.5 was dropped (GROUNDING_RECALIBRATION_2026-10.md, finding 4; backup slide B1). Unverifiable: argmax of the three probabilities is neutral. It says nothing about truth; it is shown next to the score (HOW_IT_WORKS.md "The verdict, next to the score"). Numbers: F1 0.963, FPR 0.059 (1/17), test split of 30, 5 copy dev = T3c; held-out 47: F1 0.927 at 0.7, 0.952 at 0.4, FPR 0.074 (2/27) = T3d; 68 cases = 39 supported + 29 failures. All from GROUNDING_RECALIBRATION_2026-10.md, analysis dated 2026-10-22, and the README table.
04 · Signal 2 · Drift

Drift: how far an agent has moved from itself

MiniLM embeds each output. Per agent, the mean of its first 20 outputs is the baseline; the mean of its latest 12 is the window. DRIFT_DETECTED fires above a cosine distance of 0.30.

3:30-4:10. Drift compares an agent with its own past, not with a reference answer. Baseline = mean embedding of its first 20 outputs; window = mean of its latest 12; DRIFT_DETECTED when the cosine distance between the two means is above 0.30. Deployment

One Azure VM

Standard_B2als_v2 (2 vCPU, 4 GB), Central India. Docker Compose: Caddy (TLS), nginx + dashboard, FastAPI backend, evaluator worker, chat service.

Nightly database backup.

CI / CD

GitHub Actions

Pull requests run the full pytest suite and the dashboard's tsc + vitest.

Closed by default

Every write needs the Caddy write password, except the chat and POST /v1/simulate. Key routes: 401 on every case variant. Refuses to start with the placeholder key.

09 · Honest limits

What did not hold up, said first

Inter-agent disagreement

Found 0 of 10 labelled contradictions on real traces (AUC 0.457 without the planner). Alert withdrawn; score only stored.

Tool-claim check

F1 0.000 on real traces: no claim found in 8,353 prose spans. It only reads counts written in digits.

Small labelled set

Grounding quality rests on 68 hand-labelled cases; only one is a neutral failure, so the data cannot say what the 0.3 weight buys.

Drift coverage

Only 24.5% of real sessions were long enough to report a drift distance at all.

One small deployment

One VM, one SQLite file, one evaluator worker; backup on the same disk; deploy not gated on the test suite; the chat runs on free LLM tiers and can be slow or refused.

8:50-9:25. Say these before being asked. Disagreement: 0 of 10 independently labelled contradictions on real multi-agent traces; with the planner excluded AUC 0.457 (chance). Alert withdrawn (COMPETITIVE_POSITIONING.md 5.2; SESSION_HANDOFF.md 14.1, 24.9.5). Tool-claim: F1 0.000 on a real-data benchmark, no claim extracted from 8,353 prose spans; 0.842 on 19 hand-written cases that used the phrasing its regex expects (TOOL_CLAIM_EXTERNAL_TEST_REPORT.md section 10).
